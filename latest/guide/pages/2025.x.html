2.1 What's new in 2025.x

2025.0.0-M2

This release is based on Spring Boot 4.0.9 and Spring Framework to 7.0.10.

  • Upgrade to Maven 3.10.0, Gradle 9.8.2

  • Upgrade to SiteMesh 2.8.0, Tomcat 11.0.27

For a complete list of changes made in this release see v2025.0.0 on GitHub.

⭐️ New Features

  • Restore support for generating old version apps of Grails and Grace #1765

  • Make reproducible builds with Gradle #1753

  • Assemble LICENSE.txt and NOTICE.txt files to published jars #1723

2025.0.0-M1

This release is based on Spring Boot 4.0.8 and Spring Framework to 7.0.9.

  • Upgrade to Groovy 5.0.8, Gradle 8.14.6

  • Upgrade to SiteMesh 2.8.0-M1, SnakeYAML 2.5, Tomcat 11.0.24

For a complete list of changes made in this release see release notes and v2025.0.0 on GitHub.

⚠️ Noteworthy Changes

  • Drop Hibernate 5.6 support Grace 2025.0 will support Hibernate 7, #1640 #1641

  • Temporarily remove support for Grace Console because the groovysh command-line repl has been migrated to JLine3 (GROOVY-8162)

⭐️ New Features

  • Add support for Grace 2025.0 and Spring Boot 4.0, 4.1 #1636

🛠 Improvements

  • Add release notes for 2025.0.0-M1

  • Update README

  • Groovy 5 adds asBoolean for File and Path meaning the file or path exists See GROOVY-10949 #1655

  • Use Spock 2.4-groovy-5.0 to support Groovy 5 #1655

🐞 Bug Fixes

  • Some STC changes in Groovy 5 #1655

  • Can’t set module for a non-primary ClassNode in Groovy 5 See GROOVY-11159 #1655

  • Place all grace dependencies into the dist directory #1679 #1666
