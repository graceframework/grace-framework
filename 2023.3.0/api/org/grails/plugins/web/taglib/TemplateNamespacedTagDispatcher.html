Package: org.grails.plugins.web.taglib

[Groovy] Class TemplateNamespacedTagDispatcher

      • org.grails.plugins.web.taglib.TemplateNamespacedTagDispatcher
      • All Implemented Interfaces and Traits:
        NamespacedTagDispatcher, InitializingBean
        @CompileStatic
class TemplateNamespacedTagDispatcher
extends GroovyObjectSupport
implements NamespacedTagDispatcher, InitializingBean

        Allows dispatching to namespaced tag libraries and is used within controllers and tag libraries to allow namespaced tags to be invoked as methods (eg. tmpl.person(model: )).
