= Configuration

Markup views configuration can be altered with `app/conf/application.yml`. Any of the properties within the link:{api}/grails/plugin/markup/view/MarkupViewConfiguration.html[MarkupViewConfiguration] class and Groovy's link:{groovyapi}/groovy/text/markup/TemplateConfiguration.html[TemplateConfiguration] class can be set.

For example:

[source,yaml]
grails:
    views:
        markup:
            compileStatic: true
            cacheTemplates: true
            autoIndent: true
            ...

Alternatively you can register a new `MarkupViewConfiguration` bean using the bean name `markupViewConfiguration` in `app/conf/spring/resources.groovy`.
