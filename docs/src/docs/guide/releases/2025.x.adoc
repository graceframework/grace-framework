=== 2025.0.0-M1

This release is based on Spring Boot 4.0.8 and Spring Framework to 7.0.9.

* Upgrade to Groovy 5.0.8, Gradle 8.14.6
* Upgrade to SiteMesh 2.8.0-M1, SnakeYAML 2.5, Tomcat 11.0.24

For a complete list of changes made in this release see link:{github}/releases/tag/v2025.0.0-M1[release notes] and link:https://github.com/orgs/graceframework/projects/22[v2025.0.0 on GitHub].


⚠️ Noteworthy Changes

* Drop Hibernate 5.6 support Grace 2025.0 will support Hibernate 7, link:{github}/issues/1640[#1640] link:{github}/issues/1641[#1641]
* Temporarily remove support for Grace Console because the groovysh command-line repl has been migrated to JLine3 (GROOVY-8162)

⭐️ New Features

* Add support for Grace 2025.0 and Spring Boot 4.0, 4.1 link:{github}/issues/1636[#1636]

🛠 Improvements

* Add release notes for 2025.0.0-M1
* Update README
* Groovy 5 adds asBoolean for File and Path meaning the file or path exists See GROOVY-10949 link:{github}/issues/1655[#1655]
* Use Spock 2.4-groovy-5.0 to support Groovy 5 link:{github}/issues/1655[#1655]

🐞 Bug Fixes

* Some STC changes in Groovy 5 link:{github}/issues/1655[#1655]
* Can't set module for a non-primary ClassNode in Groovy 5 See GROOVY-11159 link:{github}/issues/1655[#1655]
* Place all grace dependencies into the dist directory link:{github}/issues/1679[#1679] link:{github}/issues/1666[#1666]
