Package: org.grails.cli.profile.tasks

[Java] Class Groovy

          • org.grails.cli.profile.tasks.Groovy 
          • public class Groovy
extends org.apache.tools.ant.taskdefs.Java

            Groovy Ant task to execute a series of Groovy statements.

            Statements can either be read in from a text file using the src attribute or from between the enclosing groovy tags.

            This class is copied from Groovy, allow to customize Binding and AntBuilder.
