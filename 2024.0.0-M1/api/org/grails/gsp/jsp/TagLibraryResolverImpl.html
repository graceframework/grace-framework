    • org.grails.gsp.jsp.TagLibraryResolverImpl
    • All Implemented Interfaces and Traits:
      GrailsApplicationAware, ServletContextAware, TagLibraryResolver, ResourceLoaderAware, BeanClassLoaderAware
      @CompileStatic
class TagLibraryResolverImpl
extends Object
implements GrailsApplicationAware, ServletContextAware, TagLibraryResolver, ResourceLoaderAware, BeanClassLoaderAware

      Resolves all of the available tag libraries from web.xml and all available JAR files. Kudos to the Freemarker (http://freemarker.sourceforge.net/) library for providing the inspiration for this code.
