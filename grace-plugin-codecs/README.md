# grace-plugin-codecs

The `grace-plugin-codecs` module is a Grace Framework plugin that provides encoding and decoding capabilities for web applications, including HTML, JavaScript, URL, and cryptographic codecs.


### CodecsGrailsPlugin

The main plugin class `CodecsGrailsPlugin` extends `Plugin`, which provided some codec artefacts:

- `HTMLCodec` - HTML encoding
- `HTML4Codec` - HTML4 encoding  
- `JavaScriptCodec` - JavaScript encoding
- `HTMLJSCodec` - HTML/JavaScript encoding
- `URLCodec` - URL encoding
- `RawCodec` - Raw (no encoding)
